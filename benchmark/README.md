# EcoToxFred benchmark

Evaluates EcoToxFred on the questions in `../test_set.json` (19 developer questions `D00`–`D18`,
6 questions derived from the "CITE Meets AI" workshop feedback `W01`–`W06`).

Each run is scored for

- **tool selection**: an expected tool was called,
- **execution accuracy**: all Cypher queries generated by `CypherSearch` are executed and their combined
  result must contain the answer columns of the reference query (`cypher`, `answer_columns`, `check`),
- **goal accuracy**: RAGAS `AgentGoalAccuracy` with an LLM judge that differs from the agent model.

## Usage

Requires the Neo4j database (see `docker-compose.yml`) and an OpenAI API key in `.streamlit/secrets.toml`
(`OPENAI_MODEL` sets the agent model; set `OPENAI_API_BASE = "https://api.openai.com/v1"`, as the app defaults to
Blablador). Run from the repository root with the pinned requirements:

```bash
python benchmark/run_benchmark.py --repetitions 3 --judge-model gpt-5      # run the agent and score
python benchmark/rejudge.py benchmark/results/<run> --judge-model gpt-5    # judge stored conversations again
python benchmark/rescore_execution.py benchmark/results/<run>             # recompute execution accuracy
python benchmark/summarize.py benchmark/results/<run>                     # tables
```

Each run directory contains `meta.json`, `runs.jsonl` (one record per question and repetition),
`messages/` (full conversations), and the summary tables.

## Results (14 November 2026, release 2026.1.0)

| Agent model | Judge | Tool selection | Execution accuracy | Goal accuracy (o3) | Median latency |
|---|---|---|---|---|---|
| GPT-4.1 | GPT-5 (twice), o3 | 96% | 74% (40/54) | 52% | 16 s |
| GPT-5 | GPT-4.1 (twice), o3 | 92% | 74% (40/54) | 63% | 52 s |

- `results/gpt-4.1_20261114/`, `results/gpt-5_20261114/`: runs, conversations, and judgements
  (`goal_<judge>.jsonl`); `summarize.py` reproduces the tables.
- `results/logs/`: console output of the runs and judgements. The benchmark ran before the 120 s query
  timeout was added; queries that blocked the database were terminated externally (`watchdog.log`).
- A pilot run used to correct reference queries and the scoring procedure is not included.
